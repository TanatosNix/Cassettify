# Configuración antes de ejecutar

No se detectaron credenciales en el código ni en el historial Git local analizado. Esta carpeta contiene una copia de las fuentes actuales; incluye cambios locales que todavía no estaban en los commits.

Se excluyeron el entorno Python, binarios de FFmpeg, instaladores, compilaciones, copias de seguridad y metadatos de Windows. Usa las instrucciones del README y `bootstrap.ps1` para preparar las dependencias. Para empaquetar la aplicación tendrás que disponer localmente de FFmpeg y de los demás requisitos.

Los datos de sesión que genere la aplicación, como cookies o perfiles WebView, no deben añadirse al repositorio. La revisión no inspeccionó tus cuentas o archivos de sesión fuera del proyecto.

No reemplaces la historia de un repositorio existente con esta copia. Para actualizar el repositorio actual hay que trasladar las exclusiones y revisar los cambios pendientes sin perder su historial.
